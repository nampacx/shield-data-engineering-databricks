# Data engineering roadmap: chapters to job skills

Use this to see which skills you can claim after each chapter, and which interview topics to rehearse.

| Chapter | Skill you can claim | Typical interview question |
|---|---|---|
| 01 Platform | Provision cloud data infrastructure as code | How do you deploy a data platform repeatably? |
| 02 Recon | Spark DataFrames and SQL | Transformations vs actions? What is lazy evaluation? |
| 03 Ingest | Incremental file ingestion | How do you ingest files that arrive late or twice? |
| 04 Delta | Table formats, ACID, MERGE | Why Delta/Parquet over CSV? How do upserts work? |
| 05 Medallion | Layered data modeling | What belongs in bronze, silver, and gold? |
| 06 Quality | Data quality and quarantine patterns | How do you stop bad data reaching consumers? |
| 07 Time travel | Versioning, auditing, recovery | How would you recover from a bad write? |
| 08 Pipelines | Declarative, incremental pipelines | Batch vs incremental vs streaming? |
| 09 Streaming | Event-time processing | What is a watermark and why do you need one? |
| 10 Jobs | Orchestration, retries, alerting | How do you make a pipeline idempotent? |
| 11 Governance | Access control, masking, lineage | How do you restrict PII columns? |
| 12 Performance | Layout, file sizing, cost control | A query got slow: where do you look? |
| 13 Bundles | Environment promotion as code | How do you promote dev to prod? |
| 14 CI/CD | Testing data code, automated deploys | How do you unit-test a transformation? |
| 15 Serving | BI serving and ML hand-off | Who consumes your gold tables and how? |
| 16 Capstone | End-to-end ownership and operations | Walk me through a pipeline you built. |

Rehearse the capstone as a 5-minute walkthrough. It is the best interview story this repo gives you.
